1. Download archive [PhasmoHook.zip](https://github.com/0xcds4r/PhasmoHook-Black/releases/download/release/PhasmoHook.zip)
2. Unpack PhasmoHook folder from archive to C:\Users\%YOUR_USER_NAME% folder
3. Run 'PhasmoHookInjector.exe' & run game
4. have fun
